# 本机个人网站与公开模板

没有本机内容包时，网站继续使用仓库中的虚构模板资料和合成素材。

本机个性化入口为 `本机私有资料/个人网站/content.json`，该目录不进入 Git。只有 `enabled: true` 才启用，`false` 或不存在时均回退到模板。个人包包含双语资料、肖像、精选作品、图文故事、图片真实尺寸，以及显式的 `assets` 白名单。人物和作品图片使用 `/personal/` URL。

开发、预览和构建只读取白名单里的媒体文件，且文件必须真实位于内容目录内；路径越界、目录联接越界、未知格式或缺失素材会被拒绝。原件目录不会被整体复制。浏览器只收到页面需要的资料字段，不收到本机文件映射。

启用内容包的构建会把选定素材输出到 `dist/personal/`。准备公开模板版本时，应先关闭或移走本机包；个人版本与匿名模板版本的构建用途应明确区分。

原始简历不直接公开。展示 PDF 应另行制作，只保留需要公开的职业资料与职业邮箱，原件保持不变。个人包最后的摄影故事链接指向本页 `#beyond-work`，避免跳到仍使用合成模板的摄影页。

`npm run check:privacy` 仍核验公开源码和模板素材。它在无 DOM 的隔离环境中加载个人版辅助模块，确保默认导出仍为模板，并保留原有文件、联系信息、凭据和素材字节校验。

运行 `node --test tests/personal-portfolio.test.mjs` 可用合成夹具验证回退、脚本转义、素材白名单和路径边界；测试不读取本机个人资料。
