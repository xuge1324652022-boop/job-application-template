# 关于页滚动叙事

关于页采用深色背景、蓝色大标题与双语内容。`AboutMotionHero` 展示原有「把想法做成影像，让内容被看见」；`AboutScrollChapter` 将三行错位标题合并为一行，再缩小并逐行点亮正文。两个章节分别衔接人物介绍和创作流程。

`AboutIdentityScene` 展示完整人物资料、六条基本信息、三组技能和六个 AI 工具，图像按原始 4:3 比例完整显示，滚动先改变遮罩可见范围，随后人物图固定并等比铺满视口：右侧简介、工具与图注同步淡出，铺满后叠加暗化蒙层并轻微回缩，基本信息与技能从暗化的照片上方滚入。工具选择继续与 `AiWorkflow` 双向同步。`ExperienceTimeline` 保留四段经历和十二组职责的完整双语正文。

`AboutObservationRail` 将三个图像示例与原有观察文字组合成横向展示：桌面固定视口区域，纵向滚动驱动轨道横移，后两张图随进入位置展开遮罩；第一张图初始完整可见。图片点击仍进入统一查看器，键盘焦点进入后续面板会定位到对应滚动位置。联系邮箱、简历下载和作品导航沿用 `ContactEnd`。

平滑滚动继续由全站 `useSmoothScroll` 单独控制。固定章节按从上到下的 `refreshPriority` 测量，避免延迟初始化导致后续横向轨道使用错误的起止位置。各组件在卸载和断点切换时撤销自己的动画，保持原有幕布转场、路由返回和查看器滚动锁的所有权。

手机、短视口和减少动态模式展示完整自然阅读布局，取消长距离固定和横向滚动。标题章节仅在宽度至少 761px、高度至少 650px 时固定；照片接管在宽度至少 761px、高度至少 561px 时生效；横向图像区还要求宽度至少 981px。

资料来源集中在 `src/data/aboutProfile.ts`，所有记录都明确标记为模板示例。公开版本使用合成图形和 example.com 地址，禁止从私人 PDF 或本机资料自动回填。

动效遵守 Vue 生命周期清理、减少动态偏好与布局批处理约定。旧版 `AboutHero`、`ProfileIntro`、`BeyondWork` 保留为历史组件与源码库示例，当前关于页不再挂载。新组件的代码和参数见对应中文动效目录中的 JSON。
