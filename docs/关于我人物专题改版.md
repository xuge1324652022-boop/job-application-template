# 关于页滚动叙事

关于页采用深色背景、蓝色大标题与双语内容。开场为连续三幕：`AboutMotionHero` 以四行身份巨字构成页面 h1（字号按文字宽度自适应，320/390px 完整可读），居中入场后整个首屏短暂固定：行组按人物边界与舞台高度实测缩放并左移避开人物图，人物图遮罩展开，完整停留片刻再退场；`AboutCollageStage` 在浅色底纸上排开倾斜图片带，主角图（始终同一 DOM 元素）脱离拼贴等比放大覆盖视口（舞台裁切超出部分），底纸随之淡出，再缩入横向轨道第一格并与整轨同步左移，完成方向/方法/协作/作品四段图文叙事（文案取自现有资料）；`AboutQuoteScene` 以整屏压暗人物图作衬底，巨型姓名进入后自述行（PROFILE_LINES）与方向行逐行点亮并上移交还滚动，人物衬底延续到随后的折叠章节。反向滚动均沿原路恢复。`AboutScrollChapter` 的两个章节分别衔接人物介绍和创作流程：先提亮双语导语并让它向上离场，再将三行标题从视口底部带入、汇合和折叠成一行；标题先缩小到原尺寸的 0.065，再上移，最后让双语正文进入并逐行点亮。字号按未变换的文字宽度测量，适配视口宽高，避免宽屏标题被裁切。

身份章节不带导语（避免与引言重复）并以人物衬底贯穿；过程章节提供导语，固定滚动距离为视口高度的 5 倍，`scrub` 为 0.35。身份章节有三行正文，总时间线为 9.8；过程章节有两行正文，总时间线为 9.7。这些是映射滚动进度的相对时标，顺序由代码中的独立阶段控制，不是自动播放秒数。无导语的复用分支使用 3.2 倍视口高度。

`AboutIdentityScene` 展示完整人物资料、六条基本信息、三组技能和六个 AI 工具。图像先按原始 4:3 比例完整显示，滚动改变遮罩范围；照片固定后先保留正文阅读行程，再通过 `x`、`y` 和等比缩放将图像中心迁移到视口中心，覆盖视口四边。简介和图注随后淡出，工具按钮与探索链接继续保持自然文档流，不参与淡出或位移。图像先放大到覆盖比例的 1.04 倍，叠加 0.58 的暗化蒙层，再轻微回缩到精确覆盖比例；基本信息与技能继续从暗化照片上方滚入。工具选择与 `AiWorkflow` 双向同步，延迟挂载时也沿用当前工具。`ExperienceTimeline` 保留四段经历和十二组职责的完整双语正文。

照片接管的总时标为 2.4，先保留 0–1 的阅读阶段，再放大、暗化和回缩。固定滚动距离为 `1.8H + readingTravel × 2.4`，其中 `readingTravel` 按完整简介溢出阅读区的距离测量；这样简介末行先通过阅读区，照片才开始覆盖。中心坐标和覆盖比例在布局刷新时重新测量，反向滚动恢复完整简介与原始照片位置。

`AboutObservationRail` 将三个图像示例与原有观察文字组合成横向展示：桌面固定视口区域，纵向滚动驱动轨道横移，后两张图随进入位置展开遮罩；第一张图初始完整可见。图片点击仍进入统一查看器。键盘焦点进入完全离屏的面板会定位到对应滚动位置；触发按钮已部分可见时保持原位置，关闭查看器后不会因恢复焦点跳到面板起点。联系邮箱、简历下载和作品导航沿用 `ContactEnd`。

首屏以下的经历、工作流、观察轨道和联系区由 `LazySection` 提前一屏加载，加载后保持挂载。占位高度持续到 `Suspense` 解析异步组件并完成挂载，`ensureReady()` 随后返回就绪；内容高度变化由 `ResizeObserver` 请求共享布局刷新。页内锚点会保留 URL 的 hash 与原有查询参数，锚点直达及浏览器历史恢复先等待延迟组件、字体和 `routeCurtainBlocked` 解除，再刷新测量，最后交由原有路由 `scrollBehavior` 定位。该门闩在幕布开始揭开时解除，使坐标在输入解锁前落位，避免等到幕布完全退出后才出现可见跳动。新导航、手动滚动或离开页面会取消旧等待，不再逐帧追逐目标位置。

滚动位置以浏览器文档为准，滚轮阻尼由全站唯一的 `useSmoothScroll` 管理。固定场景按 `refreshPriority` 从上到下测量：拼贴叙事 40、人物引言 35、身份章节 30、过程章节 20、观察轨道 10。字体、图像及延迟挂载后的刷新请求统一交给可取消的布局队列，避免过早测量后续轨道。各组件在卸载和断点切换时撤销自己的动画，保留原有幕布转场、路由返回和查看器滚动锁的所有权。

手机、短视口和减少动态模式展示完整自然阅读布局，取消长距离固定和横向滚动。标题章节仅在宽度至少 761px、高度至少 650px 且允许动态时固定；人物引言要求宽度至少 761px、高度至少 620px 且允许动态；拼贴叙事与横向图像区要求宽度至少 981px、高度至少 650px 且允许动态。

资料来源集中在 `src/data/aboutProfile.ts`，所有记录都明确标记为模板示例。公开版本使用合成图形和 example.com 地址，禁止从私人 PDF 或本机资料自动回填。

动效遵守 Vue 生命周期清理、减少动态偏好与布局批处理约定。旧版 `AboutHero`、`ProfileIntro`、`BeyondWork` 保留为历史组件与源码库示例，当前关于页不再挂载。新组件的代码和参数见对应中文动效目录中的 JSON。

## 2026-10-24 原站对齐改版

用户提供参考视频的原站 `wonjyou.studio/about/`。抓取原站全页（29 帧、计算样式与视觉分析）后确认其真实设计语言为：左侧常驻竖排罗马数字章节导航（当前章红色高亮、底部奶油"LET'S CONNECT"胶囊）、整页 `#0A0A0A/#050505` 深底配奶油巨字与珊瑚红 `rgb(239,81,67)` 强调、`avantt` 700 字重配约 -4% 字距、81px 主张段落 / 135px 身份词 / 281px 章节巨字的字阶体系，以及深底与奶油纸底交替的章节节奏。据此重写关于页开场与中段，保留既有拼贴、字形放大与折叠章节机制：

- 新增 `AboutSideRail`：桌面（≥981px 且高度 ≥620px）左侧 56px 竖排章节导航，罗马数字 I–VII 对应开场/主张/方向词/叙事/实践/方式/联系七个锚点，ScrollTrigger 观察点亮当前章，底部奶油胶囊直达联系区；窄屏不渲染。
- `AboutMotionHero` 重写：右侧全出血人物图（clipPath 展开）铺底，英文姓名大写巨字（约 16vw 两行）压图自下错峰进入，中文姓名作红色斜签叠在字角，左下方向词与主张小字；滚动不固定，巨字 0.3H、照片 -0.14H、小字 0.12H 三速视差离场。原四行轨道与重排固定段移除。
