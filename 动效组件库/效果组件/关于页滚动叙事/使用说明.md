# 关于页深色滚动叙事

关于页滚动叙事：姓名巨字与可选人物插画开场，主张逐行点亮，三层身份标题向内裁切后缩小，纵向身份列表末词从实心笔画放大。纸底简介、两条倾斜图带、卡片直接扩展至全屏并接入连续横向简历长卷、成果、能力、横向履历、真实实践场景和联系区依次展开。手机图带使用原生横滚，简历纵向完整阅读，减少动态时静态阅读。个人素材和电话均由可选本机内容包提供，缺包保持公开模板回退。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 按SideRail、首屏、TAGLINE主张上移、同照片前的身份字形放大、方向词双向横移、倾斜拼贴与横向故事、WHO I AM纸底章节、个人资料、双层作品图带揭示实习摘要、完整经历、HOW I WORK、工作流、观察轨道和联系组合。
2. AboutWordZoom紧接AboutQuoteScene，传入lang、双语word与label；本页word为我是谁/WHO I AM，focusIndex为1/6，refreshPriority为44。两幕共用aboutPortrait.css和aboutQuotePortrait，背景Src/Srcset仍可由宿主覆盖；独立字形放大后，后续章节仍保留折叠缩小。
3. 首屏以下的重区块（经历、工作流、观察轨道、联系）用LazySection包裹并配minHeight占位：提前一屏加载异步chunk，Suspense解析并经过nextTick确认挂载后才移除占位、解除aria-busy并完成ensureReady()；ResizeObserver申请共享布局刷新，已加载内容不卸载。
4. 锚点与历史滚动恢复通过页面注册的prepareScroll等待四个LazySection.ensureReady()、字体和routeCurtainBlocked解除，再最终测量并交还原有路由scrollBehavior一次定位。门闩在幕布开始揭开时解除，定位不再等到幕布完全退出，避免输入解锁后出现可见的锚点跳动；新请求或卸载时取消旧请求。
5. 将路由揭幕与覆盖层状态派生为active，传给首屏及个人介绍；以v-model:active-tool把个人介绍工具和原有工作流同步。
6. 向AboutScrollChapter提供稳定name、英文heading、双语label与双语lines；需要导语先读再进入标题时传lead，保留互补标题行和独立正文节点。
7. 监听AboutObservationRail的open(item,trigger)事件，接入页面既有VisualViewer；保留from查询参数的摄影与海报续读链接。
8. 保留深色--ab-*主题变量和各组件的自然流回退样式；固定舞台必须以浏览器原生文档滚动为基准。
9. 本机个人内容包由宿主Vite插件可选注入document中的#personal-portfolio JSON；personalPortfolio.ts只读取类型化内容。包提供个人资料、人像、作品、故事与响应式尺寸；没有启用包时所有入口继续显示公开模板。复制动效源码不会自动携带本机内容包或其素材。 可选portraits.hero/quote/card/profile分别用于满幅首屏、主张衬底、人物小卡与个人资料；旧包无该字段时逐项回退原portrait，源码包不携带本机PNG。
10. AboutExperienceReveal放在个人资料之后、完整ExperienceTimeline之前，传lang；读取既有EXPERIENCE、WORKS与可选selectedWorks，不另写一份履历或把摘要当全部正文。图带使用现有作品，链接进入原#work-*段落。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。
