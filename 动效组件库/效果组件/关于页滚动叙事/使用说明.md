# 关于页深色滚动叙事

关于页以蓝色大标题建立节奏，将三行标题随滚动汇合、折叠和缩小，再逐行提亮双语正文；自然阅读流中的个人介绍使用图像遮罩与逐字提亮，照片随后固定放大铺满视口完成场景接管；工作之外使用原生纵向滚动驱动的固定横向图像轨道。四个组件各自管理动画，页面统一协调工具选择和完整图像查看器。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 在AboutView式页面按首屏、身份章节、个人介绍、经历、过程章节、工作流、工作之外、联系的叙事顺序组合组件。
2. 首屏以下的重区块（经历、工作流、观察轨道、联系）用LazySection包裹并配minHeight占位：进入视口前一屏才加载异步chunk，锚点点击或带hash进入时转急载并在挂载后定位。
3. 将路由揭幕与覆盖层状态派生为active，传给首屏及个人介绍；以v-model:active-tool把个人介绍工具和原有工作流同步。
4. 向AboutScrollChapter提供稳定name、英文heading、双语label与双语lines，并保留互补标题行和独立正文节点。
5. 监听AboutObservationRail的open(item,trigger)事件，接入页面既有VisualViewer；保留from查询参数的摄影与海报续读链接。
6. 保留深色--ab-*主题变量和各组件的自然流回退样式；固定舞台必须以浏览器原生文档滚动为基准。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。
