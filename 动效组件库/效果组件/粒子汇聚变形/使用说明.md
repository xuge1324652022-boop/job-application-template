# 粒子汇聚变形演示页

按参考视频整页复刻的三段式演示路由 /morph：深底巨字开场 TRANSFORMING IDEAS INTO DIGITAL REALITIES（末行珊瑚红强调，幕布揭开后错峰上移入场）；固定段落内，散布的奶油/珊瑚色粒子随滚动进度汇聚成示例求职者姓名首字母 E（离屏画布对字母像素采样得到目标点集，每粒子独立延迟与缓动，倒滚沿原路散开）；末段为双列圆角合成图网格，进入视口逐张浮现。文案保留视频原句作为效果演示，图片全部来自仓库合成素材，不包含任何真实人物或项目。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 访问 /morph（懒加载路由，独立于六卡导航）
2. 开场入场在路由幕布揭开后播放
3. 继续滚动驱动粒子汇聚与网格浮现

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/粒子汇聚变形.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。

状态：`active`。关联效果：[关于页滚动叙事](../关于页滚动叙事/效果介绍与解析.json)。
